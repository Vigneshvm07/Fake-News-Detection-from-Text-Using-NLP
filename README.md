# Fake News Detection from Text Using NLP

## Project Overview

Fake News Detection from Text Using NLP is a web-based application
designed to analyze news articles, headlines and social media claims.

The system uses Natural Language Processing concepts to identify
linguistic patterns that may indicate unreliable or suspicious content.

The application classifies submitted content into three categories:

1. Likely Reliable
2. Needs Verification
3. Potentially Fake

The project also provides a visual dashboard showing analysis
statistics and recent detection history.

---

# Objectives

The main objectives of this project are:

- Detect potentially fake news from text.
- Apply Natural Language Processing concepts.
- Identify suspicious words and phrases.
- Detect clickbait language.
- Identify excessive emotional language.
- Detect strong certainty claims.
- Identify reliability-related vocabulary.
- Generate a confidence score.
- Provide visual analytics.
- Maintain recent analysis history.
